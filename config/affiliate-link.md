# Affiliate-Link — zentrale Konfiguration

> **Das ist die EINZIGE Stelle, an der der Link steht.** Alle Skripte verweisen
> hierher. Einmal eintragen → überall aktuell.

## Dein Promolink

```
AFFILIATE_LINK = YOUR_AFFILIATE_LINK
```

**So bekommst du ihn:** Digistore24-App → Affiliate-Marktplatz → „KI Speed
Business" → Button **„Promolink kopieren"** (siehe Screenshot der Anfrage).
Den kopierten Link oben statt `YOUR_AFFILIATE_LINK` einsetzen.

## Kurzlink (empfohlen für Videos)

Ein roher Digistore24-Link ist lang und wirkt in der Bio/„Link in Bio" unsauber.
Lege dir einen Kurzlink an (z. B. eigene Domain, oder ein Link-in-Bio-Tool) und
trage ihn hier ein:

```
KURZLINK = z. B. deinedomain.de/ki   (leitet auf AFFILIATE_LINK weiter)
```

## Wo der Link am Ende landet

- **NICHT** direkt im Video eingebrannt (Plattformen mögen keine Fremdlinks im Clip).
- In die **Bio / „Link in Bio"** des jeweiligen Profils (TikTok, Instagram, YouTube).
- Der gesprochene/eingeblendete CTA sagt: „Link in meiner Bio / in der Beschreibung".

## Pflicht: Werbekennzeichnung

Affiliate-Videos sind **Werbung** und müssen gekennzeichnet werden.
Details siehe [`../strategie/compliance-kennzeichnung.md`](../strategie/compliance-kennzeichnung.md).
